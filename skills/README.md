# Skills

Each skill is a folder containing:
- `SKILL.md` (contract + docs)
- implementation `.py`
- `tests/`

## First wave (Phase 1)
1. `crypto/ta_scanner` – multi-asset confluence scanner
2. `x_growth/thread_factory` – thread & reply generators
3. `self_improve/code_evolver` – meta skill that improves the OS
4. `bbotbook/` – integrator with existing BbotBook cards & skills
5. `research/` – research-to-skill factory

Skills are first-class. Agents load them via the SkillLoader.
